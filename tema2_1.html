Fase 1: Apertura (Activación y Contextualización)

Caso Real: Brecha de Target Corp mediante Acceso de Terceros

En 2013, 40 millones de tarjetas bancarias fueron robadas de Target. Los atacantes no atacaron el servidor central directamente; accedieron con las credenciales robadas a un proveedor de aire acondicionado (HVAC) que tenía acceso sin segmentación a la red interna donde residían los puntos de venta (POS).

La falta de segmentación de red (VLANs), reglas estrictas de firewall perimetral y un sistema de detección de intrusos (IDS) permitió a los intrusos moverse lateralmente por meses sin ser detectados.

Preguntas Detonadoras de Laboratorio

  1. ¿Por qué tener un antivirus instalado no te protege si dejas el puerto 3389 (RDP) o 445 (SMB) abierto a todo Internet?
  2. ¿Cuál es la diferencia operativa entre un Firewall Stateful (filtra paquetes y estados de conexión) y un IDS/IPS (analiza firmas de tráfico en tiempo real)?
  3. Si un usuario pierde su laptop corporativa, ¿de qué sirve la contraseña de Windows si el disco no tiene cifrado completo con BitLocker?

Fase 2: Desarrollo Conceptual (Mecanismos de Hardening y Red)

1. Los Dos Pilares del Endurecimiento Operativo

Configuración Local de Seguridad

  • Gestión de Actualizaciones: Servidores WSUS centrales para pruebas previas a producción y clasificación de parches (Críticos, Seguridad, Acumulativos).
  • Firewall Local: Bloqueo de conexiones entrantes no solicitadas por perfil (Dominio, Privado, Público).
  • Cifrado de Almacenamiento: BitLocker con chip TPM 2.0 para discos del sistema y EFS para carpetas confidenciales individuales.
  • Permisos NTFS y ACL: Asignación granular basada en grupos; eliminación de permisos globales a "Todos" (Everyone).

Configuración de Red y Perímetro

  • Firewall Perimetral: Políticas de denegación por defecto (Default Drop / Deny All Inbound).
  • Detección de Intrusos (IDS/IPS): Motores como Suricata o Snort para inspección profunda de paquetes (DPI) y alertas en tiempo real.
  • Protocolos Seguros: IPsec (túneles cifrados en Capa 3 de red) y HTTPS con TLS 1.3 (cifrado extremo a extremo en Capa de Aplicación).
Arquitectura de Defensa en Profundidad (Defense-in-Depth)

Fase 3: Demostración y Modelado con Scripts Reales

A continuación se demuestran comandos clave en PowerShell y Linux para el endurecimiento de servidores y reglas de firewall:

Reglas de Firewall Avanzado (PowerShell) Windows Defender Firewall
# 1. Bloquear todo el tráfico entrante por defecto en todos los perfiles
PS> Set-NetFirewallProfile -Profile Domain,Public,Private -DefaultInboundAction Block

# 2. Abrir únicamente puerto HTTPS (443) para el servidor web seguro
PS> New-NetFirewallRule -DisplayName "Servidor HTTPS Seguro" -Direction Inbound -LocalPort 443 -Protocol TCP -Action Allow

# 3. Habilitar Cifrado de Unidad con BitLocker y TPM
PS> Enable-BitLocker -MountPoint "C:" -EncryptionMethod XtsAes256 -UsedSpaceOnly -TpmProtector
Hardening de Servidor Linux (UFW & OpenSSL) Bash Console
# Configuración de políticas base en UFW
$ sudo ufw default deny incoming
$ sudo ufw default allow outgoing
$ sudo ufw allow 22/tcp comment 'SSH Administrativo'
$ sudo ufw enable

Problemario de Taller y Prácticas de Laboratorio (40% Firmas)

10 Ejercicios
1. Configuración de Windows Update vía GPO: Configura la directiva de grupo local (`gpedit.msc`) para que las actualizaciones se descarguen automáticamente pero solo se instalen a las 23:00 hrs.
2. Hardening de Cuentas Locales: Deshabilita la cuenta integrada de "Invitado" y renombra la cuenta "Administrador" mediante línea de comandos.
3. Bloqueo de Puertos Peligrosos: Crea una regla de firewall en Windows Defender para bloquear todo el tráfico entrante al puerto 445 (SMB) desde redes públicas.
4. Permisos Granulares NTFS: Crea una carpeta compartida llamada `Contabilidad` y asigna permisos de Solo Lectura a usuarios estándar y Control Total únicamente al grupo Administradores.
5. Cifrado con EFS: Cifra un archivo de texto con EFS, exporta el certificado de descifrado a una memoria USB y prueba que otro usuario no pueda abrirlo.
6. Análisis de Reglas de Firewall Perimetral: Diseña una tabla de 6 reglas de filtrado para un router empresarial que hospeda un servidor web público.
7. Detección de Intrusos (Snort / Suricata): Escribe una regla de IDS para detectar un ping sweep (ICMP echo request masivo) contra la red interna.
8. Certificado SSL Autofirmado: Genera un certificado X.509 con OpenSSL y configúralo en un servidor web local para habilitar HTTPS.
9. Política de Desinfección Antivirus: Configura Microsoft Defender Antivirus para realizar escaneos diarios rápidos y cuarentena automática de amenazas severas.
10. Manual de Instalación y Hardening (Evidencia 2.1.1): Redacta el manual paso a paso con capturas de pantalla de la configuración local y de red realizada en el laboratorio.
