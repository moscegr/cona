Lenguaje Algorítmico, Pseudocódigo y Control de Flujo

El paso fundamental hacia el desarrollo de software: domina el uso de variables, constantes, expresiones lógicas (`Y`, `O`, `NO`), estructuras condicionales (`SI-ENTONCES-SINO`) y bucles repetitivos (`MIENTRAS`, `PARA`) mediante pseudocódigo estructurado.

Apertura: ¿Cómo se estructura la mente de un programador?

Aprender a programar no consiste en memorizar comandos en inglés; consiste en aprender a organizar el razonamiento lógico para resolver problemas del mundo real. Una vez que dominas el pseudocódigo, puedes programar en cualquier lenguaje: Python, JavaScript, C++, Rust o crear Inteligencia Artificial.

Concepto Clave: "El pseudocódigo es un lenguaje intermedio en español estructurado que te permite diseñar la lógica antes de escribir código en una computadora."
2

Elementos Clave del Lenguaje Algorítmico

Variables y Tipos de Datos
  • Variable: Espacio de memoria que puede cambiar su contenido (ej. edad = 16).
  • Constante: Valor fijo que no cambia (ej. IVA = 0.16).
  • Tipos: Entero, Real (decimal), Carácter, Cadena (texto) y Booleano (Verdadero/Falso).
Operadores Lógicos y Aritméticos
  • Aritméticos: +, -, *, /, % (módulo o residuo).
  • Relacionales: >, <, >=, <=, == (igual), != (distinto).
  • Lógicos: Y (AND), O (OR), NO (NOT).
🔁 Estructuras de Control Fundamentales:
Condicional SI-ENTONCES-SINO: Ejecuta un bloque u otro según si una condición lógica resulta Verdadera o Falsa.
Bucle MIENTRAS / PARA: Repite automáticamente un conjunto de instrucciones mientras se cumpla una condición.

Ejemplo Paso a Paso en Pseudocódigo

[ALGORITMO EN PSEUDOCÓDIGO FORMAL]
ALGORITMO CalcularPromedioConalep
DEFINIR calif1, calif2, calif3, promedio COMO REAL;
ESCRIBIR "Ingresa la calificación 1:";
LEER calif1;
ESCRIBIR "Ingresa la calificación 2:";
LEER calif2;
ESCRIBIR "Ingresa la calificación 3:";
LEER calif3;
promedio ← (calif1 + calif2 + calif3) / 3;
SI promedio >= 7.0 ENTONCES
ESCRIBIR "¡Acreditado con éxito! Tu promedio final es: ", promedio;
SINO
ESCRIBIR "En asesoría complementaria. Tu promedio es: ", promedio;
FINSI;
FINALGORITMO

Gran Proyecto Integrador Final: Calculadora / Sistema Automatizado

Proyecto de Cierre Semestral

Como proyecto de cierre del semestre, diseñen en equipo un sistema o calculadora automatizada en pseudocódigo y diagrama de flujo que resuelva un problema real de su especialidad técnica (cálculo de nómina con descuentos, control de inventario, índice de masa corporal con diagnóstico médico o cobro de estacionamiento):

Componentes del Proyecto Final:
  • 1. Planteamiento del problema: Descripción clara de qué calcula el sistema y a quién beneficia.
  • 2. Modelo IPO: Definición exacta de entradas, variables, fórmulas y salidas.
  • 3. Diagrama de flujo: Diagrama vectorial completo en Draw.io con decisiones y ciclos.
  • 4. Pseudocódigo estructurado: Código ordenado con variables declaradas y estructuras de control.
  • 5. Demostración en vivo: Prueba de escritorio que demuestre que el programa no falla con ningún dato.
