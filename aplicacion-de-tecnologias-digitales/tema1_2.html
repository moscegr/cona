Apertura: El Costo Real del Software Privativo

Una pequeña empresa o escuela que adquiere 20 computadoras gasta más de \$80,000 pesos al año en renovaciones de licencias de software privativo. Al adoptar soluciones de código abierto como GNU/Linux, LibreOffice y Firefox, obtiene mayor seguridad, total legalidad y costo cero en licencias.

Dato Legal: El software libre garantiza independencia tecnológica y elimina los riesgos de multas o vulnerabilidades provocadas por programas 'piratas'.
2

Desarrollo Conceptual: Contenidos Formativos

1. Licencia GPL (GNU General Public License)

Garantiza el derecho a ejecutar, modificar y redistribuir el software bajo la condición de que cualquier derivado conserve la misma licencia libre (Copyleft).

2. Creative Commons (CC)

Licencias flexibles para obras multimedia: Atribución (BY), No Comercial (NC), Sin Obras Derivadas (ND) y Compartir Igual (SA).

3. Conectividad y Redes

Ancho de banda, latencia, protocolos TCP/IP, Wi-Fi 6 y cableado Ethernet estructurado.

4. Navegadores y Sistemas

Sistemas operativos (Linux, Windows, Android) y navegadores web seguros (Firefox, Brave).

5. Niveles de Acceso

Permisos de lectura, escritura y ejecución (rwx) y privilegios de Administrador vs Usuario estándar.

📏 6. Unidades de Medida Oficiales:
1 Byte = 8 bits
1 KB = 1024 Bytes
1 MB = 1024 KB
1 GB = 1024 MB

Ejemplo Guiado: Propuesta Técnica para una Empresa

Estructura formal para el informe técnico de modernización digital:

[INFORME TÉCNICO DE INFRAESTRUCTURA DIGITAL]
• 1. Requerimientos de Hardware: Computadoras con CPU 4 núcleos, 16 GB RAM, SSD 512 GB NVMe, Switch Gigabit y Punto de Acceso Wi-Fi 6.
• 2. Software y Licencias: Sistema Operativo GNU/Linux Ubuntu LTS (Licencia GPL) + Suite LibreOffice (Costo $0 MXN).
• 3. Conectividad y Niveles de Acceso: Conexión de 200 Mbps simétricos, segmentación de red para clientes y cuentas de usuario sin privilegios root.
• 4. Justificación de Ahorro: Ahorro directo de $32,000 MXN en adquisición inicial de licencias privativas.
