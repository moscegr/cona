Fase 1: Apertura (Activación y Reto Provocador)

Reto Disruptivo: ¿Cómo un bucle infinito tumba servidores de millones de usuarios?

HackLab #04

En un videojuego online o app bancaria, si un programador olvida incrementar la variable de control dentro de un bucle MIENTRAS, el procesador se satura al 100% de CPU calculando la misma condición eternamente, congelando el servidor y arruinando la experiencia de millones de personas.

🔥 Reto de Cátedra: Todo bucle debe tener una condición de salida garantizada y toda decisión condicional debe contemplar el camino alternativo SINO.

Fase 2: Desarrollo Conceptual (Condicionales y Bucles)

1. Estructuras Condicionales
  • Simple: SI (condicion) ENTONCES ... FINSI
  • Doble: SI (condicion) ENTONCES ... SINO ... FINSI
  • Anidada: Decisiones múltiples en cascada (ej. Semáforo o Calificaciones A-B-C-F).
  • Operadores: AND (&&), OR (||), NOT (!).
2. Estructuras Repetitivas (Bucles)
  • MIENTRAS (While): Evalúa la condición antes de entrar al ciclo (0 a N veces).
  • PARA (For): Ciclo con contador definido desde un valor inicial hasta un límite.
  • Contador: i = i + 1 | Acumulador: total = total + precio.

Fase 3: Modelado de Algoritmo con Ciclo y Acumulador

[PSEUDOCÓDIGO FORMAL: SUMATORIA DE N CALIFICACIONES]
ALGORITMO PromedioNotas
  DEFINIR n, i, nota, suma, promedio COMO REAL;
  suma ← 0;
  ESCRIBIR "Ingrese la cantidad de materias:";
  LEER n;
  PARA i ← 1 HASTA n CON PASO 1 HACER
    ESCRIBIR "Ingrese nota ", i, ":";
    LEER nota;
    suma ← suma + nota; // Acumulador
  FINPARA;
  promedio ← suma / n;
  SI promedio >= 7.0 ENTONCES
    ESCRIBIR "¡ALUMNO ACREDITADO! Promedio: ", promedio;
  SINO
    ESCRIBIR "ALUMNO EN REGULARIZACIÓN. Promedio: ", promedio;
  FINSI;
FINALGORITMO
