Fase 2: Desarrollo Conceptual (SIEM, Syslog y Event IDs Críticos)

Syslog RFC 5424

Protocolo estándar (puerto UDP 514). Clasifica mensajes en 8 niveles de severidad: desde 0 (Emergency) hasta 7 (Debug).

Windows Security Logs

ID 4624: Login exitoso.
ID 4625: Login fallido (indicador de fuerza bruta).
ID 4720: Usuario nuevo creado.

Motores SIEM & IDS Snort

Correlación en tiempo real: Si IP X genera 10 eventos 4625 en 1 minuto → Disparar alerta crítica y bloqueo automático.

Fase 3: Script Parser de Detección de Ataques en Python

[SCRIPT THREAT HUNTING: detector_fuerza_bruta.py]
import re
from collections import defaultdict

# Simulación de lectura de /var/log/auth.log en Linux
log_entries = [
    "Failed password for root from 198.51.100.23 port 54221 ssh2",
    "Failed password for admin from 198.51.100.23 port 54224 ssh2",
    "Failed password for user from 198.51.100.23 port 54229 ssh2",
    "Accepted password for cgarcia from 192.168.1.10 port 49152 ssh2"
]

conteo_fallos = defaultdict(int)
for linea in log_entries:
    match = re.search(r"Failed password.*from ([\d\.]+) port", linea)
    if match:
        ip = match.group(1)
        conteo_fallos[ip] += 1

for ip, fallos in conteo_fallos.items():
    if fallos >= 3:
        print(f"[ALERTA SOC CRÍTICA] Posible Fuerza Bruta desde IP: {ip} ({fallos} intentos fallidos)")

Bitácora de Monitoreo y SIEM (40% Firmas)

10 Retos
Reto 1 (Filtrado de Eventos en Visor de Windows): Utiliza el Visor de Eventos para crear una vista personalizada que filtre únicamente los IDs 4625 (fallos de inicio de sesión).
Reto 2 (Configuración de Servidor Syslog Centralizado): Configura el archivo /etc/rsyslog.conf en Linux para recibir logs remotos de switches y routers en el puerto UDP 514.
Reto 3 (Regla de Detección de Snort IDS): Escribe una regla de Snort para detectar peticiones HTTP que contengan la cadena /etc/passwd (Path Traversal).
Reto 4 (Análisis de Logs de Acceso Web Nginx/Apache): Escribe un comando con awk y sort para listar las 5 IPs que más peticiones han realizado al servidor web.
Reto 5 (Detección de Movimiento Lateral): Identifica en los logs cuándo una misma cuenta de usuario inicia sesión en 3 computadoras distintas en menos de 5 minutos.
Reto 6 (Integración de Agente Wazuh EDR): Documenta la instalación de un agente Wazuh en Windows/Linux y su vinculación con el servidor central de monitoreo.
Reto 7 (Detección de Exfiltración de Datos con Wireshark): Captura tráfico DNS anómalo y detecta paquetes con cargas útiles codificadas en Base64 (DNS Tunneling).
Reto 8 (Dashboard de Métricas en Grafana / Kibana): Diseña un panel gráfico que muestre la tasa de peticiones por segundo y el mapa geográfico de IPs atacantes.
Reto 9 (Playbook de Respuesta a Incidentes SOAR): Define el flujo automatizado: Si detección == Ransomware → Aislar interfaz de red de la máquina en 3 segundos.
Reto 10 (Monitoreo y Análisis de Eventos - Evidencia AE 2.2.1): Presenta el reporte de monitoreo continuo con logs analizados, alertas clasificadas y medidas tomadas para el 20% SAE.
