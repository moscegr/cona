Fase 1: Apertura (Activación y Contextualización)

Caso Real: Auditoría Forense de Fraude Bancario

En una institución financiera, un empleado desleal modificaba los saldos de cuentas corrientes aprovechando permisos directos sobre la base de datos. Gracias a un Trigger de Auditoría (AFTER UPDATE) que registraba automáticamente en una tabla oculta el usuario, la IP, la hora exacta, el saldo anterior (OLD.saldo) y el nuevo saldo (NEW.saldo), el equipo de seguridad detectó y comprobó el fraude en minutos.

Preguntas Diagnósticas

  1. ¿Cuál es el peligro de ejecutar una sentencia DELETE FROM tabla; o UPDATE tabla SET precio=0; sin la cláusula WHERE?
  2. ¿Qué diferencia existe entre un INNER JOIN (solo registros coincidentes) y un LEFT JOIN (todos los de la izquierda más coincidentes)?
  3. ¿En qué eventos de base de datos se activa un Trigger y por qué en una operación INSERT solo existe la variable NEW?

Fase 2: Desarrollo Conceptual (DML, JOINs y Triggers)

Combinación de Tablas (JOINs)
  • INNER JOIN: Retorna filas que tienen valores coincidentes en ambas tablas.
  • LEFT JOIN: Retorna todas las filas de la tabla izquierda y las coincidentes de la derecha.
  • RIGHT JOIN: Retorna todas las filas de la tabla derecha y las coincidentes de la izquierda.
  • GROUP BY & HAVING: Agrupa tuplas y aplica filtros sobre totales agregados (SUM, AVG, COUNT).
Disparadores (Triggers)
  • Momento: BEFORE (para validación de datos antes de guardar) o AFTER (para auditoría posterior).
  • Operación: INSERT, UPDATE o DELETE.
  • Variables: NEW (nuevo valor entrante) y OLD (valor previo almacenado).

Fase 3: Script de Consultas SQL y Disparadores

-- 1. CONSULTA DE SELECCIÓN CON INNER JOIN Y AGRUPACIÓN SELECT c.nombre_carrera, COUNT(a.matricula) AS total_alumnos
FROM carreras c
INNER JOIN alumnos a ON c.id_carrera = a.id_carrera
GROUP BY c.nombre_carrera
HAVING total_alumnos >= 5
ORDER BY total_alumnos DESC;
-- 2. DISPARADOR DE AUDITORÍA HISTÓRICA (AFTER UPDATE) DELIMITER // ;
CREATE TRIGGER trg_auditoria_precio
AFTER UPDATE ON productos
FOR EACH ROW
BEGIN
  IF OLD.precio <> NEW.precio THEN
    INSERT INTO bitacora_precios (id_producto, precio_anterior, precio_nuevo, fecha_modificacion, usuario)
    VALUES (OLD.id_producto, OLD.precio, NEW.precio, NOW(), USER());
  END IF;
END // ;
DELIMITER ;
