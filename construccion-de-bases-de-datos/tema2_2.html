Diseño de Vistas de Seguridad, Formularios y Generación de Reportes

Creación de vistas virtuales con `CREATE VIEW` para simplificación de consultas complejas y enmascaramiento de datos confidenciales, estructuración de formularios de captura de datos y generación de reportes ejecutivos para la toma de decisiones directivas.

Fase 1: Apertura (Activación y Contextualización)

Protección de Datos Personales y Salarios Mediante Vistas

El departamento de Recursos Humanos de una empresa necesita que el personal de recepción consulte el directorio de empleados (Nombre, Extensión, Departamento, Correo) sin tener acceso a la tabla física completa donde se encuentran almacenados los Salarios, Número de Seguro Social y Cuentas Bancarias.

Una Vista (VIEW) actúa como una tabla virtual que expone únicamente las columnas autorizadas, garantizando el cumplimiento de la ley de protección de datos.

Preguntas Diagnósticas

  1. ¿Por qué una vista no almacena datos físicamente en el disco y cómo se actualiza automáticamente cuando cambian las tablas base?
  2. ¿Qué requisitos debe cumplir una vista para ser actualizable (es decir, permitir INSERT o UPDATE directos)?
  3. ¿Cómo se integra una vista SQL con un reporte interactivo en una aplicación web o de escritorio?

Fase 2: Desarrollo Conceptual (Vistas y Reportes)

Beneficios de las Vistas SQL
  • Seguridad de Datos: Oculta columnas sensibles otorgando permisos solo sobre la vista (GRANT SELECT ON v_directorio).
  • Simplificación: Encapsula JOINs de 5 tablas en un simple SELECT * FROM v_resumen_ventas.
  • Consistencia: Estandariza cálculos complejos de impuestos y fórmulas de negocio.
Componentes de un Reporte Ejecutivo
  • Encabezado: Logotipo institucional, título del reporte, fecha de emisión y filtros aplicados.
  • Cuerpo / Detalle: Tablas formateadas con alineación numérica a la derecha y tipos de moneda.
  • Pie / Resumen: Subtotales por grupo, totales generales, promedios y firmas de autorización.

Fase 3: Script de Creación y Consulta de Vistas

-- 1. CREACIÓN DE VISTA SEGURA DE ALUMNOS (OCULTANDO DATOS SENSIBLES) CREATE OR REPLACE VIEW v_alumnos_activos AS
SELECT a.matricula, CONCAT(a.nombre, ' ', a.apellidos) AS nombre_completo, a.correo, c.nombre_carrera
FROM alumnos a
INNER JOIN carreras c ON a.id_carrera = c.id_carrera
WHERE c.activo = TRUE;
-- 2. CONSULTA Y REPORTE DIRECTO SOBRE LA VISTA SELECT nombre_carrera, COUNT(matricula) AS inscritos
FROM v_alumnos_activos
GROUP BY nombre_carrera;

-- 3. ELIMINACIÓN DE VISTA
DROP VIEW IF EXISTS v_alumnos_activos;
