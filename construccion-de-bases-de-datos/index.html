Construcción de Bases de Datos

Planeación didáctica orientada al ciclo de vida completo de bases de datos relacionales: Modelado Entidad-Relación (MER), normalización estricta (1FN, 2FN, 3FN, BCNF), definición física DDL, consultas avanzadas DML con JOINs, disparadores (Triggers), vistas, transacciones ACID (bloqueo 2PL) y seguridad con roles y privilegios en MySQL / MariaDB / PostgreSQL.

126 Horas Semestrales 7 Horas / Semana (18 Semanas) 7 Evidencias Oficiales SAE (100%)

Encuadre Profesional de Gestión de Datos (Catedrático Cruz Enrique García)

"En este módulo formativo, los estudiantes transitan desde el análisis de requerimientos del usuario hasta la implementación física y segura de bases de datos relacionales. No se trata únicamente de escribir sentencias SQL, sino de garantizar la integridad referencial, la normalización sin redundancias, el rendimiento de consultas mediante índices y la consistencia transaccional (ACID). Cada unidad incorpora simuladores interactivos en JavaScript nativo para modelar, normalizar y consultar bases de datos en tiempo real."
