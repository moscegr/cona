Fase 1: Apertura (Activación y Contextualización)

De la Pizarra al Motor de Producción

Una vez que el modelo lógico ha sido normalizado a 3FN, llega el momento crucial de materializarlo en el motor de base de datos. La selección adecuada de los tipos de datos (ej. INT vs BIGINT, VARCHAR(100) vs TEXT, DECIMAL(10,2) para dinero) y la correcta definición de restricciones CONSTRAINT garantizan que el servidor rechace automáticamente cualquier dato inválido.

Preguntas Diagnósticas Detonadoras

  1. ¿Por qué nunca se debe utilizar FLOAT o DOUBLE para campos monetarios y se exige DECIMAL(10,2)?
  2. ¿Qué sucede si intentas insertar una fila en una tabla hija con un valor de FOREIGN KEY que no existe en la tabla padre?
  3. ¿Cuál es la diferencia entre DROP TABLE (destruye estructura y datos) y TRUNCATE TABLE (vacía datos reiniciando contadores)?

Fase 2: Desarrollo Conceptual (Comandos DDL y Restricciones)

Comandos DDL Principales
  • CREATE DATABASE / SCHEMA: Crea el contenedor de datos en el motor.
  • CREATE TABLE: Define la estructura de columnas, tipos y restricciones.
  • ALTER TABLE: Modifica tablas en caliente (añadir, modificar o eliminar columnas y llaves).
  • DROP TABLE / DATABASE: Elimina permanentemente objetos del esquema.
Restricciones de Integridad (Constraints)
  • PRIMARY KEY: Identificador único y no nulo de la tupla.
  • FOREIGN KEY: Clave foránea que referencia una PK en otra tabla.
  • UNIQUE: Evita valores duplicados (ej. CURP, Correo).
  • NOT NULL & DEFAULT: Obligatoriedad y valor predeterminado.
  • CHECK: Regla lógica de validación (ej. CHECK(edad >= 18)).

Fase 3: Script DDL Estándar en MySQL / MariaDB

-- 1. CREACIÓN DE LA BASE DE DATOS CREATE DATABASE IF NOT EXISTS conalep_escolar CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
USE conalep_escolar;
-- 2. TABLA PADRE (CARRERAS) CREATE TABLE carreras (
  id_carrera INT AUTO_INCREMENT PRIMARY KEY,
  clave_oficial VARCHAR(15) NOT NULL UNIQUE,
  nombre_carrera VARCHAR(100) NOT NULL,
  activo BOOLEAN DEFAULT TRUE
) ENGINE=InnoDB;
-- 3. TABLA HIJA CON CLAVE FORÁNEA (ALUMNOS) CREATE TABLE alumnos (
  matricula VARCHAR(12) PRIMARY KEY,
  nombre VARCHAR(60) NOT NULL,
  apellidos VARCHAR(80) NOT NULL,
  correo VARCHAR(100) NOT NULL UNIQUE,
  id_carrera INT NOT NULL,
  CONSTRAINT fk_alumno_carrera FOREIGN KEY (id_carrera)
    REFERENCES carreras(id_carrera)
    ON UPDATE CASCADE ON DELETE RESTRICT
) ENGINE=InnoDB;
