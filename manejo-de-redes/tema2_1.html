Fase 1: Apertura (Activación y Contextualización)

El Estándar Industrial de Telecomunicaciones: Cisco IOS CLI

En los centros de datos más grandes del mundo, los administradores no utilizan interfaces gráficas que consumen recursos. Toda la configuración de routers de borde y switches de distribución se realiza mediante conexiones de Consola (cable transpuesto rollover) o SSH seguro a través de la CLI de Cisco IOS.

Preguntas Diagnósticas

  1. ¿Qué diferencia existe entre el prompt Router> (EXEC Usuario) y Router# (EXEC Privilegiado)?
  2. ¿Por qué se debe utilizar enable secret en lugar de enable password?
  3. ¿Qué comando guarda permanentemente la configuración de la memoria RAM (running-config) a la NVRAM (startup-config)?

Fase 2: Desarrollo Conceptual (Jerarquía de Comandos Cisco IOS)

1. Modo EXEC Usuario Router>

Monitoreo básico y comandos de visualización limitados (ping, traceroute, show version).

2. Modo EXEC Privilegiado Router#

Acceso total con comando enable. Ejecuta comandos show avanzados, debug y copia de archivos.

3. Modo Configuración Global Router(config)#

Acceso con configure terminal. Modifica parámetros que afectan a todo el dispositivo.

Fase 3: Script de Configuración Inicial Estandarizada

router_initial_setup.ios Cisco IOS Command Script
Router> enable
Router# configure terminal
Router(config)# hostname R1_Chilpancingo
R1_Chilpancingo(config)# no ip domain-lookup
R1_Chilpancingo(config)# enable secret CiscoClass2026!
R1_Chilpancingo(config)# banner motd # ACCESO RESTRINGIDO - CONALEP OFICIAL #
R1_Chilpancingo(config)# line console 0
R1_Chilpancingo(config-line)# password CiscoPass
R1_Chilpancingo(config-line)# login
R1_Chilpancingo(config-line)# exit
R1_Chilpancingo(config)# interface FastEthernet 0/0
R1_Chilpancingo(config-if)# description Enlace LAN Laboratorio
R1_Chilpancingo(config-if)# ip address 192.168.10.1 255.255.255.0
R1_Chilpancingo(config-if)# no shutdown
R1_Chilpancingo(config-if)# end
R1_Chilpancingo# copy running-config startup-config

Problemario de Comandos Cisco IOS (40% Firmas)

10 Ejercicios
1. Jerarquía de Modos IOS: Dibuja en tu libreta el mapa de transición entre Modo EXEC Usuario, EXEC Privilegiado, Config Global, Interfaz y Línea con los comandos de entrada y salida (exit / end).
2. Configuración de Hostname y Búsqueda DNS: Escribe la secuencia de comandos para asignar el nombre SW_PISO1 y deshabilitar las búsquedas de nombres accidentales en DNS.
3. Cifrado de Contraseñas del Sistema: Aplica el comando service password-encryption y explica cómo transforma una clave en texto claro a Type 7 en el running-config.
4. Configuración de Banner Legal MOTD: Diseña un mensaje de advertencia legal delimitado por almohadillas (#) que cumpla con normativas de seguridad informática.
5. Asignación de IP en Interfaz FastEthernet: Modela la configuración de la interfaz Fa0/1 con la IP 10.0.0.1/24 y habilitación con no shutdown.
6. Análisis de la Tabla de Direcciones MAC: Ejecuta show mac-address-table en un switch Catalyst 2960 y explica la diferencia entre entradas estáticas y dinámicas.
7. Configuración de Líneas VTY para Telnet/SSH: Configura 5 terminales virtuales (line vty 0 4) con autenticación por contraseña.
8. Respaldo de Configuración a Servidor TFTP: Documenta el comando copy running-config tftp: ingresando la dirección IP del servidor y nombre de archivo.
9. Restauración de Fábrica en Switch Cisco: Detalla los comandos erase startup-config y delete flash:vlan.dat seguidos de reload.
10. Práctica de Topología LAN (Evidencia AE 2.1.1): Realiza la topología con router, switch y 2 PCs en Cisco Packet Tracer para el 15% SAE.
