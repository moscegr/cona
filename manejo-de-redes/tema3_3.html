Fase 1: Apertura (Activación y Contextualización)

La Necesidad de Comunicación Controlada entre Departamentos

Las VLANs segmentan el tráfico para evitar tormentas de broadcast y aumentar la seguridad. Sin embargo, en una red real los usuarios de la VLAN 10 (Alumnos) y de la VLAN 20 (Docentes) necesitan acceder a un servidor web o de base de datos ubicado en la VLAN 30 (Servidores).

El enrutamiento Inter-VLAN proporciona el puente de capa 3 necesario para que las diferentes redes se comuniquen aplicando políticas de seguridad y filtrado.

Preguntas Detonadoras

  1. ¿Por qué el método tradicional de enrutamiento Inter-VLAN (un cable físico por cada VLAN) es inviable en redes con más de 10 VLANs?
  2. ¿En qué consiste el modelo Router-on-a-Stick y cómo una sola interfaz física se subdivide en múltiples subinterfaces virtuales?
  3. ¿Qué sucede si olvidas configurar el comando no shutdown en la interfaz física principal del router?

Fase 2: Desarrollo Conceptual (Subinterfaces y Encapsulación dot1Q)

Subinterfaces Lógicas en Cisco IOS
  • Son interfaces virtuales basadas en software asociadas a una interfaz física (ej. Fa0/0.10, Fa0/0.20).
  • Cada subinterfaz actúa como el Default Gateway para los hosts pertenecientes a esa VLAN específica.
  • Requiere definir el protocolo de etiquetado con encapsulation dot1Q <vlan-id> antes de asignar la dirección IP.
Errores Comunes de Configuración
  • Puerto del Switch en Modo Acceso: El puerto del switch conectado al router DEBE estar en modo trunk.
  • Desajuste de VLAN ID: El número de VLAN en encapsulation dot1Q no coincide con el ID de la VLAN del switch.
  • Gateway Incorrecto en Clientes: La IP del host no apunta a la IP de su respectiva subinterfaz.

Fase 3: Demostración y Modelado en Packet Tracer

! 1. CONFIGURACIÓN DEL ROUTER (ROUTER-ON-A-STICK) Router(config)# interface FastEthernet 0/0
Router(config-if)# no shutdown
Router(config-if)# exit
Router(config)# interface FastEthernet 0/0.10
Router(config-subif)# encapsulation dot1Q 10
Router(config-subif)# ip address 172.17.10.1 255.255.255.0
Router(config-subif)# interface FastEthernet 0/0.20
Router(config-subif)# encapsulation dot1Q 20
Router(config-subif)# ip address 172.17.20.1 255.255.255.0
Router(config-subif)# interface FastEthernet 0/0.99
Router(config-subif)# encapsulation dot1Q 99 native
Router(config-subif)# ip address 172.17.99.1 255.255.255.0
Router(config-subif)# end
! 2. CONFIGURACIÓN DEL SWITCH CATALYST Switch(config)# interface FastEthernet 0/5
Switch(config-if)# switchport mode trunk
Switch(config-if)# switchport trunk native vlan 99
Switch(config-if)# end

Problemario de Enrutamiento Inter-VLAN (40% Firmas)

10 Ejercicios
1. Esquema de Router-on-a-Stick: Dibuja en tu libreta la topología física y lógica de un router conectado por un solo cable troncal a un switch con 3 subinterfaces.
2. Configuración de 3 Subinterfaces dot1Q: Escribe los comandos IOS para configurar Fa0/0.10, Fa0/0.20 y Fa0/0.30 con sus respectivas IPs.
3. Asignación de VLAN Nativa en Router: Modela la subinterfaz Fa0/0.99 con la sentencia encapsulation dot1Q 99 native.
4. Análisis de la Tabla de Enrutamiento: Interpreta la salida de show ip route en el router confirmando que las 3 redes aparecen como directamente conectadas (C).
5. Diagnóstico con Traceroute entre VLANs: Ejecuta tracert 172.17.30.254 desde PC1 y describe el salto intermedio por el Gateway del router.
6. Corrección de Error de Encapsulación: ¿Qué error muestra el router si intentas asignar ip address en una subinterfaz antes de escribir encapsulation dot1Q?
7. Enrutamiento en Switch de Capa 3 (Multilayer Switch): Compara el enfoque Router-on-a-Stick con el enrutamiento SVI mediante el comando ip routing en un switch Catalyst 3560.
8. Verificación de Subinterfaces con Show IP Interface Brief: Explica cómo confirmar que las subinterfaces lógicas están en estado up/up.
9. Mitigación de Cuellos de Botella: Propón una solución para evitar la saturación del enlace troncal hacia el router utilizando agregación de enlaces EtherChannel (LACP).
10. Práctica Integradora Final de Enrutamiento (Evidencia AE 3.3.1): Presenta el proyecto completo de conmutación y enrutamiento en Packet Tracer para el 15% SAE.
