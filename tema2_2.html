Fase 1: Apertura (Activación y Contextualización)

La Importancia Crítica del Monitoreo Activo

Según los reportes globales de ciberseguridad (Mandiant M-Trends), el tiempo promedio que un intruso permanece dentro de una red empresarial antes de ser descubierto (Dwell Time) es de más de 16 días.

Los atacantes ya estaban registrados en los archivos de registro (logs), pero nadie estaba leyendo ni correlacionando las alertas. El monitoreo proactivo es la diferencia entre frustrar un ataque en minutos o sufrir la filtración de la base de datos.

Preguntas Detonadoras

  1. Si un usuario intenta autenticarse 150 veces en 2 minutos desde una IP externa a las 3:00 AM, ¿qué tipo de ataque es y qué ID de evento genera en Windows?
  2. ¿Por qué es obligatorio respaldar digitalmente las configuraciones de los routers y firewalls antes de aplicar cualquier modificación?
  3. ¿Cómo se programa un script para que envíe un reporte diario del estado de seguridad sin intervención humana?

Fase 2: Desarrollo Conceptual (Gestión de Bitácoras y Logs)

1. Identificadores de Eventos Críticos (Windows Event IDs)

Event ID 4625 Inicio de Sesión Fallido: Indica contraseña incorrecta o intento de fuerza bruta contra una cuenta.
Event ID 4624 Inicio de Sesión Exitoso: Registra el tipo de logon (Tipo 2: Consola, Tipo 3: Red, Tipo 10: RDP).
Event ID 4720 / 4726 Creación / Eliminación de Usuario: Alerta crítica ante posibles cuentas 'puerta trasera' creadas por atacantes.
Event ID 1102 / 104 Vaciado de Bitácora (Log Cleared): Sospecha máxima; los atacantes borran registros para ocultar sus huellas.

Fase 3: Demostración y Modelado con Scripts

Extracción automatizada de intentos fallidos en PowerShell y exportación a reporte CSV para la evidencia AE 2.2.1:

Auditoría Automatizada de Intentos de Acceso (PowerShell) Windows PowerShell
# Buscar los últimos 50 eventos de inicio de sesión fallidos (Event ID 4625)
PS> Get-WinEvent -FilterHashtable @{LogName='Security'; Id=4625} -MaxEvents 50 |
    Select-Object TimeCreated, Id, Message |
    Export-Csv -Path "C:\Seguridad\Reportes\Logins_Fallidos_$(Get-Date -Format yyyyMMdd).csv" -NoTypeInformation

# Respaldo automático de la configuración del Firewall
PS> netsh advfirewall export "C:\Seguridad\Respaldos\Firewall_Backup_$(Get-Date -Format yyyyMMdd).wfw"

Problemario de Taller y Evidencias Semanales (40% Firmas)

10 Ejercicios
1. Inspección en Visor de Eventos: Abre `eventvwr.msc`, navega a Registros de Windows > Seguridad y localiza los últimos 3 eventos registrados identificando su ID y usuario.
2. Simulación de Error de Contraseña: Bloquea tu equipo e introduce una contraseña errónea 3 veces. Luego verifica en los logs la aparición del Event ID 4625.
3. Tarea Programada de Auditoría: Crea una tarea programada con el Programador de Tareas de Windows que ejecute un script de respaldo de logs todos los viernes a las 18:00 hrs.
4. Formulario de Modificación de Configuraciones: Redacta el formato de solicitud técnica para cambiar la política de contraseñas de 8 a 12 caracteres.
5. Respaldo de Políticas de Grupo (GPO): Exporta las directivas de seguridad locales a un archivo de plantilla `.inf` mediante `secedit.exe`.
6. Análisis de Logs de Servidor Web (Apache/Nginx): Analiza un fragmento de log con códigos HTTP 403 Forbidden y 404 Not Found para detectar un escaneo de directorios.
7. Lista de Cotejo de Respaldo: Diseña un instrumento de cotejo con 5 puntos de validación para asegurar la integridad de las copias de seguridad de las configuraciones.
8. Alerta Temprana de Disco Lleno: Configura un contador en el Monitor de Rendimiento (`perfmon.msc`) que envíe una alerta si el espacio libre en disco cae por debajo del 15%.
9. Detección de Elevación de Privilegios: Documenta en qué circunstancias se registra el Event ID 4672 (Asignación de privilegios especiales de administrador).
10. Reporte Ejecutivo Periódico (Evidencia 2.2.1): Elabora el informe final del estado de seguridad con gráficas de intentos de acceso y estatus de respaldos.
