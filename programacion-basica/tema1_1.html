Fase 1: Apertura (Activación y Contextualización)

Caso Real: Telemetría y Control de Vuelo en Drones con Python

En los sistemas modernos de vehículos aéreos no tripulados (UAVs / Drones), microcomputadoras embebidas (como Raspberry Pi con Python) leen sensores de altitud (barómetros), orientación (giróscopos) y posicionamiento GPS a más de 50 lecturas por segundo.

Si un programador confunde un dato entero (`int`) con un punto flotante (`float`) o comete un error en la precedencia de operadores matemáticos en la fórmula de sustentación, el dron pierde el equilibrio y colisiona. La precisión en los tipos de datos es crítica.

Preguntas Detonadoras (Diagnóstico Inicial)

  1. ¿Por qué una computadora no puede "adivinar" lo que queremos y requiere instrucciones estrictamente secuenciales y no ambiguas?
  2. En Python, si sumas `5 + 5` el resultado es `10`, pero si sumas `"5" + "5"` el resultado es `"55"`. ¿Qué propiedad de los tipos de datos explica esta diferencia?
  3. ¿Cuál es la función de un depurador (Debugger) y en qué se diferencia de simplemente leer el código en pantalla?

Fase 2: Desarrollo Conceptual (Algoritmia, Tipos y Operadores)

1. Algoritmos, Diagramas de Flujo y Modelo IPO

Todo programa informático sigue la arquitectura IPO (Input - Process - Output):

Entrada (Input) Captura de datos desde teclado (`input()`), sensores o archivos. Siempre ingresa inicialmente como cadena de texto (`str`).
Proceso (Process) Transformación matemática, cálculos con operadores aritméticos y evaluaciones lógicas en la CPU.
Salida (Output) Despliegue de resultados formateados en consola (`print()`), f-strings o almacenamiento en disco.
Asignación de Memoria y Referencias a Objetos en Python

2. Tipos de Datos Primitivos y Jerarquía de Operadores

Tipos Primitivos de Python
  • int: Enteros de precisión arbitraria (ej. 42, -1500).
  • float: Números de punto flotante IEEE 754 (ej. 3.14159, -0.05).
  • str: Cadenas de caracteres Unicode inmutables (ej. "CONALEP").
  • bool: Valores de verdad booleanos (True o False).
Operadores y Precedencia (PEMDAS)
  • 1. Paréntesis: ( ) para forzar orden de evaluación.
  • 2. Potencia: ** (asociativa por derecha).
  • 3. Multiplicación, División real y entera, Módulo: *, /, //, %.
  • 4. Suma y Resta: +, -.
  • 5. Relacionales: ==, !=, <, >, <=, >=.
  • 6. Lógicos: not, luego and, finalmente or.

Fase 3: Demostración y Modelado Paso a Paso en Python 3

A continuación se modela un programa completo en Python 3 que implementa el ciclo IPO, conversión de tipos (Casting) y validación de expresiones:

calculo_sustentacion_drone.py Python 3.11+
# 1. ENTRADA DE DATOS (Input y Casting a Float)
peso_drone_kg = float(input("Ingrese el peso total del dron (kg): "))
num_motores = int(input("Ingrese número de rotores (ej. 4 u 8): "))

# 2. PROCESO (Cálculos con Operadores Aritméticos y Fórmulas)
gravedad = 9.81 # m/s^2
fuerza_empuje_requerida = (peso_drone_kg * gravedad) * 2.0 # Factor de seguridad 2x
empuje_por_motor = fuerza_empuje_requerida / num_motores
es_seguro = (empuje_por_motor > 5.0) and (num_motores % 2 == 0)

# 3. SALIDA FORMATEADA CON F-STRINGS
print(f"\n--- REPORTE DE TELEMETRÍA ---")
print(f"Empuje Total: {fuerza_empuje_requerida:.2f} Newtons")
print(f"Empuje por Motor: {empuje_por_motor:.2f} N/motor")
print(f"Configuración Válida: {es_seguro}")

5. Calculadora de Autonomía de Batería de Dron: Elabora un programa que solicite la capacidad de la batería en mAh y el consumo en Amperes por rotor para calcular el tiempo de vuelo estimado en minutos.

7. Cálculo de Interés Compuesto: Implementa la fórmula \(A = P(1 + r/n)^{nt}\) en Python utilizando el operador de potencia ** con variables descriptivas según la guía de estilo PEP 8.
8. Formateo Avanzado con F-Strings: Diseña una nota de venta o ticket de compra con columnas alineadas a la derecha y precios con signo de pesos usando especificadores de formato (ej. {precio:>10.2f}).

10. Pruebas Unitarias Manuales (Evidencia AE 1.1.1): Diseña una tabla con 5 casos de prueba (entradas válidas, valores límite y entradas inválidas) para el programa de cálculo de telemetría.
