Programación Básica en Python

Planeación didáctica orientada al desarrollo de software mediante algoritmia estructurada, diseño de diagramas de flujo, estructuras de control (`if/elif/else`, `for/while`), programación modular con funciones, manejo dinámico de memoria (listas, pilas, colas, diccionarios) y depuración en Python 3.

126 Horas Semestrales 7 Horas / Semana (18 Semanas) 4 Evidencias Oficiales SAE (100%)

Encuadre Pedagógico del Módulo (Catedrático Cruz Enrique García)

"La programación no consiste en memorizar sintaxis, sino en aprender a descomponer problemas complejos en instrucciones lógicas precisas. Durante estas 126 horas (7 horas semanales), adaptamos el programa de estudio al lenguaje Python 3, la herramienta estándar de la industria para desarrollo de software, ciencia de datos y control de hardware. Cada sesión se estructura en 5 fases pedagógicas con simuladores interactivos en JavaScript nativo, depuración paso a paso y problemarios para su portafolio de firmas."
