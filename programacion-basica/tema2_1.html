Fase 1: Apertura (Activación y Contextualización)

El Principio DRY: Don't Repeat Yourself

Imagina un software de control de vuelo donde la fórmula para calcular la distancia euclidiana entre el dron y la base se repite en 40 lugares distintos del código. Si mañana el sensor cambia de unidades de metros a pies, tendrías que modificar 40 archivos manualmente, corriendo el riesgo de olvidar uno y provocar un desastre.

Las funciones encapsulan la lógica en un solo lugar reutilizable, testeable y mantenible.

Preguntas Detonadoras

  1. ¿Qué ocurre en la memoria RAM de la computadora cuando una función termina su ejecución con return?
  2. En Python, cuando pasas un número a una función no se modifica afuera, pero cuando pasas una lista sí puede modificarse. ¿Qué diferencia a los objetos mutables de los inmutables?
  3. ¿Qué es una función recursiva y cuál es el peligro de olvidar definir el caso base (Base Case)?

Fase 2: Desarrollo Conceptual (Anatomía de Funciones y Scope)

1. Anatomía y Parámetros en Python

Parámetros y Argumentos Flexibles
  • Por Valor por Defecto: def conectar(ip, puerto=8080):.
  • Tupla de Argumentos (`*args`): Recibe número variable de parámetros posicionales.
  • Diccionario de Argumentos (`**kwargs`): Recibe parámetros nombrados clave-valor.
Alcance de Variables (Scope LEGB)
  • Local: Variables creadas dentro del cuerpo de la función.
  • Enclosing: Variables en funciones anidadas (Closures).
  • Global: Variables accesibles en todo el archivo del módulo.
  • Built-in: Funciones nativas de Python (len(), range()).

Fase 3: Demostración y Creación de Módulos

A continuación se modela la creación de un módulo reutilizable `telemetria.py` y su consumo en el script principal:

telemetria.py (Librería / Módulo) Módulo Reutilizable
"""Módulo para el cálculo de cinemática y navegación de drones."""

def calcular_distancia(x1: float, y1: float, x2: float, y2: float) -> float:
    """Calcula la distancia euclidiana 2D en metros."""
    return ((x2 - x1)**2 + (y2 - y1)**2) ** 0.5

def consumo_estimado(distancia_m: float, velocidad_ms: float = 10.0) -> tuple:
    """Retorna tiempo de viaje (s) y batería estimada consumida (%)."""
    tiempo_seg = distancia_m / velocidad_ms
    bateria_consumida = (tiempo_seg / 60.0) * 3.5 # 3.5% por minuto
    return tiempo_seg, bateria_consumida
main.py (Script de Integración) Ejecución Principal
from telemetria import calcular_distancia, consumo_estimado

d = calcular_distancia(0.0, 0.0, 300.0, 400.0)
t, bat = consumo_estimado(d, velocidad_ms=12.5)

print(f"Distancia a objetivo: {d:.2f} m")
print(f"Tiempo de vuelo: {t:.1f} seg | Batería requerida: {bat:.1f}%")

Problemario de Taller y Evidencias Semanales (40% Firmas)

10 Ejercicios
1. Función de Cálculo de IMC: Diseña una función `calcular_imc(peso_kg, altura_m)` que retorne el índice de masa corporal y el diagnóstico clínico como tupla.
2. Función con Argumentos Arbitrarios (`*args`): Escribe una función `promediar_calificaciones(*notas)` que acepte cualquier cantidad de notas numéricas y retorne el promedio.
3. Función con Parámetros Nombrados (`**kwargs`): Elabora una función `crear_perfil_dron(**specs)` que construya un diccionario formateado con las especificaciones del dron.
4. Demostración de Mutabilidad: Escribe una función que modifique una lista recibida por parámetro y explica por qué el cambio se refleja en la variable original.
5. Factorial Recursivo: Implementa la función recursiva `factorial(n)` documentando el caso base y el caso recursivo.
6. Búsqueda Binaria Recursiva: Diseña una función recursiva `busqueda_binaria(lista, objetivo, inicio, fin)` sobre una lista ordenada.
7. Creación de Librería de Geometría: Crea el módulo `geometria.py` con funciones para área de círculo, rectángulo y triángulo; luego impórtalo desde otro archivo.
8. Función Pura vs Función con Efectos Secundarios: Explica la diferencia entre una función que solo calcula y retorna un valor frente a una que modifica variables globales con `global`.
9. Función Recursiva de Fibonacci: Escribe `fibonacci_recursivo(n)` y traza a mano el árbol de llamadas para \(n = 4\).
10. Pruebas de Integración (Evidencia AE 2.1.1): Diseña un script de pruebas unitarias que invoque 5 funciones de tu módulo y verifique que los retornos coincidan con los esperados.
