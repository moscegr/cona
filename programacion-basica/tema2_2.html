Fase 1: Apertura (Activación y Contextualización)

El Desastre del Vuelo 501 de Ariane 5: Un Error de Memoria

En 1996, el cohete Ariane 5 de la Agencia Espacial Europea se autodestruyó a 37 segundos del lanzamiento debido a una excepción de software no capturada: un número flotante de 64 bits se intentó convertir a un entero de 16 bits, provocando un desbordamiento (Overflow) que congeló las computadoras de guía.

En la ingeniería de software moderna, validar los datos de entrada y envolver operaciones críticas en bloques `try / except` es obligatorio para garantizar la resiliencia del sistema.

Fase 2: Desarrollo Conceptual (Estructuras de Datos y Manejo de Errores)

1. Estructuras Lineales: Listas, Pilas (LIFO) y Colas (FIFO)

Pila (Stack - LIFO) Last-In, First-Out: El último elemento en entrar es el primero en salir. Operaciones:
  • append(elem): Empuja (Push) a la cima.
  • pop(): Extrae (Pop) de la cima.
Cola (Queue - FIFO) First-In, First-Out: El primer elemento en llegar es el primero en ser atendido. Se implementa con collections.deque:
  • append(elem): Encola al final.
  • popleft(): Desencola del frente en tiempo \(\mathcal{O}(1)\).
Comparativa de Flujo: Pila LIFO vs Cola FIFO

2. Gestión Profesional de Errores con `try / except`

Excepciones Frecuentes en Python:
  • ValueError: Conversión inválida (ej. int("abc")).
  • ZeroDivisionError: División matemática entre cero.
  • IndexError: Índice fuera de los límites de la lista.
  • KeyError: Búsqueda de una clave inexistente en diccionario.
Cláusulas de Manejo:
  • try: Bloque con código propenso a fallar.
  • except Exception as e: Captura y recuperación del error.
  • else: Se ejecuta solo si NO hubo ninguna excepción.
  • finally: Se ejecuta SIEMPRE (limpieza y cierre).

Fase 3: Demostración y Modelado en Código

Implementación de una Cola de Tareas de Vuelo con `collections.deque` y validación con `try/except`:

cola_misiones_dron.py Python 3.11+
from collections import deque

# 1. Crear Cola FIFO de Waypoints
cola_misiones = deque()

def encolar_mision(nombre_mision: str, altitud_m: float):
    try:
        alt = float(altitud_m)
        if alt <= 0:
            raise ValueError("La altitud debe ser estrictamente positiva.")
        cola_misiones.append({"mision": nombre_mision, "altitud": alt})
        print(f"[ENCOLADO] {nombre_mision} a {alt}m")
    except ValueError as err:
        print(f"[ERROR DE VALIDACIÓN]: {err}")

def procesar_siguiente_mision():
    if not cola_misiones:
        print("No hay misiones pendientes en la cola.")
        return None
    mision_actual = cola_misiones.popleft() # FIFO O(1)
    print(f"[EJECUTANDO]: {mision_actual['mision']} -> Volando a {mision_actual['altitud']}m")
    return mision_actual
